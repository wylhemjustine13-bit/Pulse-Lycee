# Hiera Sociale

Hiera Sociale est un projet de réseau social destiné à la communauté d'un lycée.

## Prototype actuel

- Interface responsive adaptée au téléphone et à l'ordinateur.
- Fil d'actualité avec publications ajoutées localement dans la page.
- Navigation visuelle entre les rubriques prévues.
- Première identité graphique Hiera Sociale.

## Lancer le prototype

Ouvrir `index.html` dans un navigateur, ou activer GitHub Pages dans les paramètres du dépôt pour publier cette page statique.

## Important : limites de cette version

Cette première version est une maquette front-end. Les publications ne sont pas enregistrées sur un serveur et aucun compte réel n'est créé. La messagerie, les profils, les signalements et la modération nécessitent un backend sécurisé avant une utilisation réelle par des élèves.

Avant tout déploiement public auprès de mineurs, il faudra prévoir notamment une authentification sécurisée, des règles de confidentialité adaptées, une modération et un processus de signalement, ainsi que l'accord et l'encadrement de l'établissement.
